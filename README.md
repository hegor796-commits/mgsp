# Бот для анализа счетов и контроля цен на материалы

Telegram-бот для автоматической проверки счетов и контроля закупочных цен на строительные и другие материалы.

## Возможности

- 📄 Загрузка и анализ счетов (PDF, Excel, Word, изображения)
- 🤖 Автоматическое извлечение данных с помощью Claude AI
- 💰 Сравнение цен с минимальными ценами из базы данных
- 📊 Формирование отчётов в форматах Excel и PDF
- 🔍 Поиск материалов и аналогов
- ⚙️ Панель администратора для управления пользователями и базой

## Требования

- Python 3.11+
- Docker и Docker Compose (для контейнерного запуска)
- Tesseract OCR с поддержкой русского языка
- Токен Telegram-бота (получить у @BotFather)
- API-ключ Anthropic

## Быстрый старт

### 1. Клонируйте репозиторий и перейдите в директорию

```bash
cd /home/user/mgsp
```

### 2. Настройте окружение

```bash
cp .env.example .env
```

Отредактируйте `.env`, вставив ваши ключи:

```
BOT_TOKEN=ваш_токен_бота
ANTHROPIC_API_KEY=ваш_ключ_anthropic
EXCEL_DB_PATH=data/database.xlsx
STORAGE_PATH=storage/
```

### 3. Запуск через Docker

```bash
docker-compose up -d
```

### 4. Запуск без Docker

```bash
pip install -r requirements.txt
python -m bot.main
```

## Первый запуск и добавление пользователей

При первом запуске автоматически создаётся база данных `data/database.xlsx`.

По умолчанию в базе есть запись с Telegram ID = 0 (системный администратор). Чтобы добавить реального пользователя-администратора:

1. Узнайте свой Telegram ID (например, через @userinfobot)
2. Откройте `data/database.xlsx`, лист «Пользователи»
3. Добавьте строку: `<ваш_id>`, `Ваше ФИО`, `admin`, `email`, `Да`, `дата`

Или временно замените `0` на ваш реальный Telegram ID и перезапустите бота.
